Inside the app

Three ways to support

Home opens into Routines, Activities, Schedules, and My Voice. Each pillar has its own job.

AAC board: tap symbols, build a sentence strip, speak it. Free Core, Quick Talk and Phrases. Premium deepens personal boards.

Focus mode

One step, or the whole board

Focus is the live session surface: dark chrome, nothing else competing for attention. Use it two ways.

One card Focus

From Steps, tap Focus. One step fills the screen. Swipe or Done when finished. Ideal when the full sequence feels too loud.

Landscape First & Then

From a First & Then board, tap Focus Mode and rotate. First and Then sit side by side. Switch to 3 steps for First / Next / Then across the width.

Voice and timer

You control the pace

  • Voice: unmute to hear each step title as it appears (Focus, Steps, First & Then, Break It Down). Mute mid-session in one tap.
  • Timer: adult starts it when the child is ready. Never auto-starts on enter.
  • Every card: set 30s to 6m (or custom) once; it repeats on every card until you clear it.
  • Auto-advance: optional. Keep it off if you want to wait for Done.

Timers are part of the Plus story on memberships. The control lives in Focus chrome next to mute.

First & Then

Shrink a busy moment to 2 or 3 cards

Suggested pairs are ready inside each pack. Or create your own, then open Focus Mode for the landscape board.

Play light, then go Focus

On the light board you see First stacked above Then, with Timer and Focus Mode in the chrome. Finish a step with a flick or double-tap.

Need even less? From Steps tap 1-2 to open Board 1-2 without leaving the session, choose 2 or 3 steps, then Focus Mode.

Example: First get toothbrush / Then put toothpaste. Rotate into Focus so both cards sit across the landscape.

Create my routine

Build a sequence from the library

Not only official packs. Pick cards from your open libraries, name the routine, save it, then run Library, Steps, First & Then or Focus like any other pack.

  1. Open Create my routine from Routines.
  2. Name it (for example Morning ready).
  3. Open a library chip, tap miniatures in order (up to 20).
  4. Drag to reorder, remove any card, then Save.
  5. Run it with the same session tools as official WOW packs.

You can also create a First & Then from any pack library: pick First + Then, or First + Next + Then.

Session toolkit

Library and Steps, same language

Library

Browse every digital card in the pack: objects and actions with the same titles and art as printed WOW decks.

Steps

Run the full sequence in order. See progress (for example 0/11), an objects strip when useful, and chrome to jump into Focus or Board 1-2.

Morning path: Library to explore cards → Steps to run the sequence → Focus when you need one quiet step.

Activities

Break It Down: flip the main action

Side A shows the main action. Side B breaks it into numbered steps. Tap a step to hear it.

Free packs: ABC, Football, Yoga. Create my activity lets families build a workout from open libraries (also up to 20 cards).

When a routine step has Break It Down, the same flip appears inside Steps and Focus.
