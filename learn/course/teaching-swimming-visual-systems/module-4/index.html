Supporting neurodiverse swimmers with visual structure

Learning objective Adapt visual systems to support sensory needs, transitions and emotional safety for neurodiverse swimmers.

Structure reduces uncertainty

Many neurodiverse learners benefit from knowing what will happen, in what order, and when something finishes. Visual schedules and skill sequences make that structure visible.

Use the same start and end routines each session when you can. Predictability builds trust before skill teaching begins.

Sensory and communication considerations

  • Offer a "next / then / finished" frame for transitions into and out of the water
  • Reduce competing visuals: show only the cards needed for this block
  • Allow processing time after pointing to a card before repeating instructions
  • Pair visuals with calm, short language rather than long explanations

Emotional safety first

If a learner is dysregulated, prioritise co-regulation and a known visual routine over introducing a new skill. Return to teaching when the learner can engage with the sequence again.

Celebrate successful steps visually (point to "done" or move the card) so progress feels concrete.
