Aquatic Pathway gold standard

PixtoLearn x clubSENsational. This is not the Launch Open / See it / Get it shell, and it is not the Neurodiversity Visual Specialist flagship. Specialist aquatic training keeps Journey, Outcomes, Blocks with concepts, In Practice, Recap and Quiz. The gold addition is a short video on every content block.

Runtime: pixtolearn-aquatic-specialist
Pathways: I (Understanding Aquatic Practice) + II (Aquatic Development and Skills Progression)
Status: Video slots live as placeholders with film briefs until clips are shot

  1. Journey

  4. Recap

Gold anatomy per block

1. FocusBlock Focus + What This Block Covers
2. See the blockShort video (or placeholder + film brief) showing the block idea in real pool practice
3. ConceptsConcept stage grid; each concept: visual, key ideas, In Practice, activity, done
4. GateReflection checkpoint + block completion checkbox

Launch gold stays separate: Open, See it, Get it, Try it, Case it, Take it, Check. Do not convert Specialist modules to that sequence.

Production rules

  • One video per content block, not per concept.
  • Prefer real pool footage; no long talking-head lectures.
  • Until filmed, keep block-video is-placeholder with a concrete brief.
  • Do not replace concept stages with Launch Try it / Case it patterns.
