Neurodiversity Visual Specialist

PixtoLearn Academy's deep specialist pathway: Visual Awareness for neurodiverse and non-verbal learners. Not a swimming pedagogy course. Not a clinical diagnosis programme. A practical system for building, placing and sustaining visual supports with Packs, WOW cards and the App across real life.

Product name: Neurodiversity Visual Specialist
Working subtitle: Visual Awareness for Neurodiverse and Non-Verbal Learners
Level: Level 2 Specialist (PixtoLearn flagship)
Shell: Specialist gold (Journey, Outcomes, Blocks with See the block video, Concepts, In Practice, Quiz). Not the short Launch Open-Check shell.
Parts: 4 parts | 14 modules + optional Practitioner portfolio
Duration: about 6 to 8 hours learning time
Price (proposed): Individual £199 | Team 10 seats £399
Audience: families, educators, TAs, therapists, support staff, swimming instructors (visual layer), organisations
Products threaded throughout: Swimming Packs, WOW Routine Cards, Keyring, App Focus
Prerequisite: Visual Teaching Foundations recommended. Packs and App course helpful.
Relation to aquatic: Module 11 covers pool/leisure visuals only. Deep aquatic practice stays in the clubSENsational x PixtoLearn co-brand Pathway I + II.
Tone: Respectful, practical, dignity-first. No deficit-only language. No meltdown spectacle.

Promise (one sentence)

After this pathway, a learner support adult can design, place and coach a shared visual system that reduces uncertainty for a neurodiverse or non-verbal person across home, school, therapy, community and leisure, using PixtoLearn tools.

Learning outcomes

  • Explain why visuals create access for neurodiverse and non-verbal learners (not rewards, not decoration).
  • Audit sensory load and redesign an environment so one visual focus can land.
  • Choose and build the right visual type: first-then, schedule, skill sequence, finished, wait, help, break, choice.
  • Use Packs, WOW cards and App Focus as one coherent system (not three separate habits).
  • Pair visual teaching with AAC without blocking communication.
  • Prioritise regulation visuals before new skill teaching.
  • Apply the method in home, school, therapy, community and pool/leisure scenarios with concrete card placements.
  • Read behaviour as communication and prevent escalation with visual options.
  • Align a multi-adult team around one shared strip and handover routine.
  • Produce a usable learner visual plan that can run the next day.

Part A. Visual awareness foundations

Build the mindset and the visual kit before setting-specific work.

Module 1: Neurodiversity, communication and visual access

About 30-35 minutes | 3 blocks

Objective: reframe support around processing and access. Non-verbal does not mean non-communicating. Visuals are access tools.

Block 1What neurodiversity means in day-to-day teaching (processing speed, sensory differences, prediction needs).
Block 2Communication beyond speech: gesture, AAC, behaviour, body language, and how visuals support receptive access.
Block 3Visuals as access, not reward, not bribe, not punishment. Dignity rules.

See the block videos: (1) Long verbal instruction vs short cue + card. (2) Learner communicates without speech (point, device, choice). (3) Same card used as access vs wrongly used as "earn this back".

In Practice: Write a one-page learner snapshot: strengths, sensory notes, communication preferences, what overwhelms, what calms.

Scenarios:

  • Staff: "He understands everything if he wants to" after a meltdown during multi-step talk.
  • Parent: stops using cards because "they should talk more".
  • New TA: talks constantly while holding cards face-down.

Solutions to lock in: one idea per cue; wait after showing; never withhold visuals for behaviour; snapshot before systems.

Quiz gate: best definition of visual support for non-verbal / neurodiverse learners.

Module 2: Sensory load and environment design

About 30-35 minutes | 3 blocks

Objective: make the environment ready so a visual system can land. Reduce load before adding teaching demand.

Block 1Load sources: noise, light, proximity, clutter, unpredictable people traffic, competing displays.
Block 2One visual focus: strip, stand, keyring or App Focus. Hide the rest.
Block 3Quick environment resets for home, classroom, therapy room, changing room, poolside.

See the block: Cluttered wall vs single sequence strip. Same learner, different engagement.

In Practice: Photo audit of your main setting. Mark 5 overload risks and 3 fixes you can do this week.

Scenarios:

  • Classroom: 40 laminated cards on the wall; learner freezes at the door.
  • Pool: echo + whistle + three adults talking; cards held in a fan of eight.
  • Home: TV on, siblings shouting, morning sequence on fridge behind magnets.

Solutions: reduce then teach; face learner with 1-4 cards only; place at eye line; turn body to shield distraction; App Focus for rehearsal in a quieter corner first.

Module 3: The visual toolkit that reduces uncertainty

About 40-45 minutes | 4 blocks

Objective: master when to use each visual type, and how short is short enough.

Block 1First-then and now-next-then for transitions.
Block 2Schedules for the day or session vs skill sequences for one task.
Block 3Finished, wait, help, break, choice boards.
Block 4Common failure: too many steps. How to cut a 12-card monster into a usable 3-5.

See the block: Hands build first-then, then a 4-step skill sequence, then a break/help pair. Cut to learner following at a door.

Try it: Match need to system type (transition, full morning, skill, dysregulation, choice).

Scenarios:

  • Family uses 20 cards for leaving the house; child freezes at shoes.
  • Therapist builds a beautiful 10-step craft sequence; learner leaves after step two.
  • School uses a full-day schedule but no "finished" meaning; anxiety rises at every change.

Solutions: start with first-then; add only what reduces uncertainty; finished must be real; help/break always available, never earned.

Part B. PixtoLearn tools for neurodiverse learners

Make Packs, WOW and App one system. Pair with AAC. Regulate before you teach.

Module 4: Packs, WOW cards and App as one system

About 35-40 minutes | 3 blocks

Objective: stop treating products as separate toys. Build one visual language across waterproof Packs, WOW routines and digital Focus.

Block 1Swimming Packs / waterproof cards: place-based teaching where water or wet hands matter.
Block 2WOW Routine Cards: home and early-years transitions (morning, leaving, mealtime, bedtime, hygiene).
Block 3App Focus: rehearsal, portable consistency, staff briefing, quieter practice before the hard environment.

Product map (teach explicitly):

  • Packs: skill and session sequences in aquatic / outdoor wet contexts.
  • WOW: everyday life sequences at child/adult learner height.
  • Keyring: portable micro-set (first-then, help, break, finished) in bags and pockets.
  • App: same symbols for Focus rehearsal and team share.

Scenarios:

  • Family has WOW at home but pool instructor invents new drawings every week.
  • School laminates photocopies that look nothing like the Packs the centre bought.
  • App used as entertainment video, not as Focus on the next step.

Solutions: shared symbol set; photo of the strip for handover; App mirrors the physical sequence; Keyring for out-of-home micro moments.

Take it: Build a "same language" plan: which tool lives where for one learner this month.

Module 5: AAC-friendly visuals and communication pairing

About 30-35 minutes | 3 blocks

Objective: pair task visuals with the learner's communication method. Do not replace speech therapy advice. Do not block AAC.

Block 1Teaching sequence vs communication board vs reward chart (sort them).
Block 2Modelling: point to next step, then offer a way to request help / break / finished.
Block 3Vocabulary consistency across home, school and therapy.

Hard rule: never remove an AAC device "so they focus on the cards".

Scenarios:

  • Staff puts device away during swimming "because it might get wet" with no waterproof alternative plan.
  • Different adults use different words for the same card (toilet / loo / potty).
  • Choice board offered only after escalation, not before.

Solutions: waterproof pouch / poolside partner holds device; agree vocabulary list; choice and break available proactively; wait after modelling.

Module 6: Regulation first: calm before teaching

About 35-40 minutes | 3 blocks

Objective: when the nervous system is in survival mode, new skills will not land. Use known visuals to co-regulate, then re-enter teaching.

Block 1Early signs ladder (body, voice, withdrawal, refusal).
Block 2Regulation visual kit: known calm routine, break, finished, sensory option cards.
Block 3Re-entry: shorten the demand, return to first-then, celebrate recovery without shame.

See the block: Two endings of the same rising moment: push through vs return to known calm visual. Prefer calm recovery footage.

Scenarios:

  • Pool: learner hits / withdraws mid skill; adult pushes to "finish the set".
  • Classroom: demand increases while ears are covered.
  • Home bedtime: new 8-step sequence introduced during already high arousal.

Solutions: reduce demand; known visuals only; co-regulate; teach later; never use removal of preferred visuals as consequence.

Part C. Settings and scenario labs

Apply the same method in five life arenas. Heavy WOW in home. Heavy Packs in pool/leisure. App everywhere as the portable copy.

Module 7: Home and family life with WOW

About 40-45 minutes | 4 blocks

Objective: install calmer everyday routines with WOW cards at learner height, with family-friendly consistency.

Block 1Morning and leaving-the-house systems.
Block 2Mealtimes, hygiene, dressing.
Block 3Bedtime and wind-down (low stimulation).
Block 4Siblings, visitors and "house chaos" adaptations.

WOW placements: bathroom mirror edge, bedroom door, shoe zone, kitchen side of fridge (clear, not buried), bag Keyring for outings.

Scenarios:

  • Morning rush: parent narrates 12 steps; child sits on floor.
  • Toothbrushing battle every night; cards exist but live in a drawer.
  • Weekend visitors: routine collapses because adults improvise.
  • Leaving for school: shoes on / bag / goodbye needs first-then, not a full day schedule.

Solutions: 3-5 WOW steps max per routine; same place every day; App Focus rehearsal the night before a hard morning; photo for babysitter / grandparent handover.

Module 8: School, early years and classroom

About 40-45 minutes | 4 blocks

Objective: use visual systems for arrival, lessons, transitions, group time and end-of-day without turning the room into visual noise.

Block 1Arrival and coat / bag / settle sequences.
Block 2Lesson access: task strip on desk, not only on the board.
Block 3Transitions: classroom to playground, assembly, lunch, taxi.
Block 4Group time and sensory breaks without shame exits.

Scenarios:

  • Whole-class visual timetable too dense for one learner who needs a personal first-then.
  • TA prompts verbally over the card every two seconds.
  • Fire drill / substitute teacher day: no portable system.
  • Playground return: meltdown at the door every time.

Solutions: personal strip + class schedule layered; prompt fade plan; Keyring / App for supply staff; pre-teach transition with Focus; break card as dignified exit.

Module 9: Therapy and clinical-adjacent settings

About 30-35 minutes | 3 blocks

Objective: keep sessions predictable for OT, SLT, physio, psychology-adjacent and keyworker work without claiming clinical authority.

Block 1Session start / work / break / finished structure.
Block 2Skill teaching with minimal verbal load inside a therapy goal.
Block 3Handover to family and school with the same symbols.

Disclaimer in module: Educational visual method. Follow the learner's clinical plans. Do not diagnose.

Scenarios:

  • Therapist changes activities every 3 minutes with no finished cue.
  • Clinic room full of toys in sight; learner cannot start.
  • Home programme sent as text paragraph; family cannot run it.

Solutions: visible session strip; hide unused materials; send photo of sequence + App Focus link; agree vocabulary with SLT/AAC team.

Module 10: Community, travel and appointments

About 35-40 minutes | 3 blocks

Objective: take visual awareness out of the building: shops, buses, waiting rooms, haircuts, medical visits.

Block 1Outing first-then and "what happens there" preview strips.
Block 2Waiting and sensory survival (headphones card, break, leave option).
Block 3Unexpected change cards (closed shop, delayed bus, different door).

Tools: Keyring + App Focus preview the night before. Optional printed mini-strip in the bag.

Scenarios:

  • Supermarket: fluorescent lights, queue, no exit plan.
  • GP waiting room: 25-minute delay, no update.
  • Haircut: cape on without warning.
  • Public transport: wrong platform / loud announcement.

Solutions: preview sequence; wait card + timer if helpful; change card ready; exit/break as valid success; rehearse in App before the real outing.

Module 11: Pool and leisure with visual structure

About 35-40 minutes | 3 blocks

Objective: apply PixtoLearn visual systems in wet, noisy leisure settings. This is the visual layer, not full aquatic skill pedagogy.

Block 1Changing room and pool entry sequences (high anxiety zone).
Block 2Lesson strip poolside: 3-5 waterproof cards, placement, prompting.
Block 3Sensory and regulation supports in water; when to stop teaching.

Cross-link: For deep aquatic practice and skills progression, open the clubSENsational x PixtoLearn Aquatic Pathway (co-brand). Keep this module focused on visuals.

Scenarios:

  • Learner refuses to leave changing room every week.
  • Instructor holds eight cards and talks over echo.
  • Whistle + shout after sensory overload.
  • Parent watches and adds more verbal demand from the side.

Solutions: changing-room first-then; one strip on stand; short cues; known calm visual; agree parent/instructor roles; App Focus rehearsal before session.

Part D. Behaviour, teams and mastery

Prevent, align adults, and prove you can run the system tomorrow.

Module 12: Behaviour as communication (visual prevention and response)

About 40-45 minutes | 4 blocks

Objective: read common behaviours as messages and use visuals to prevent and respond without shame.

Block 1Possible messages: too much, too fast, unclear, no break path, sensory pain, seeking connection.
Block 2Preventive visuals before the hard moment.
Block 3In-the-moment visual responses (help, break, finished, first-then restart).
Block 4What never to do: visuals as punishment; public shame; forced compliance theatre.

Scenarios:

  • Running from the room at transition time.
  • Shutdown under the table after verbal overload.
  • Hitting when a preferred activity ends with no warning.
  • Team removes favourite cards "until behaviour improves".

Solutions: warn with visuals before endings; break/help always present; repair and re-enter; restore access to the system immediately.

Module 13: Consistency across people and settings

About 30-35 minutes | 3 blocks

Objective: one shared visual language across mum, dad, TA, therapist, instructor and respite.

Block 1Why inconsistency recreates uncertainty.
Block 2Handover tools: photo of strip, vocabulary list, App copy, who may edit.
Block 3Team agreement one-pager.

Scenarios:

  • Three adults, three different "getting ready" sequences.
  • School bans outside visuals; home and pool use PixtoLearn.
  • Respite carer improvises with phone photos of random objects.

Solutions: shared symbol set; nominate a system owner; App as source of truth; minimum viable strip that every setting can run.

Module 14: Capstone lab: one learner, one visual plan

About 45-55 minutes | guided builder

Objective: produce a complete, usable plan for one real learner.

Plan sectionsSnapshot; environment fixes; core systems (first-then + one routine + one skill); regulation kit; product map (WOW / Packs / Keyring / App); team agreement; 7-day trial checklist.
See itWorked anonymised example across home + school + one leisure setting.
Try itInteractive builder form (future platform) or downloadable worksheet.
Case itImprove a weak plan (too many steps, no finished, no team share, products unused).
CheckSelf-rubric: clear, short, placed, shared, regulable, product-backed.

Completion standard: plan is specific enough that a new adult could run tomorrow's first routine without a meeting.

Module 15 (optional): Practitioner portfolio

About 45-60 minutes guided | certification track

Objective: evidence for PixtoLearn Practitioner (Neurodiversity Visual Specialist). Practice standard, not a clinical licence.

EvidenceRedacted plan; placement photos; 7-day reflection; team agreement; consent record.
EthicsConsent, dignity, no shame content, no public posting of distress.
AssessPass rubric for certificate pathway (future).

Production and assessment notes

  • Shell: Specialist gold per block (Focus, See the block video, Concepts, In Practice, Gate). End each module with Quiz.
  • Videos: 60-90s, subtitled, consented, dignity-first. Cover home WOW, school, community Keyring, pool Packs, App Focus.
  • Language: en-GB, plain, respectful. Avoid em dashes in learner-facing copy.
  • Assessment: module quizzes + Module 14 plan rubric. Optional Module 15 portfolio for Practitioner track.
  • Upsell path: Foundations / Launch Pathway -> Neurodiversity Visual Specialist -> Packs + WOW + App -> optional Practitioner. Aquatic co-brand Pathway for instructors who need deep pool pedagogy.
  • Do not duplicate: Launch swimming Module 4 stays a short intro. Adults LD and Dementia niches stay separate after this flagship.
  • Build order: Part A and B first (shared engine), then Part C setting labs (film-heavy), then Part D and portfolio.
