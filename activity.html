    Choose a module Why Activity exists

    The problem

    Sessions fall apart when the plan lives only in words

    Too many lessons rely on spoken cues, memory and hope. Learners miss the sequence. Instructors repeat themselves. Transitions spike anxiety. Activity was built to fix that — with the same visual method that already works in the water.

    Without structure

    Unclear expectations

    What am I doing? For how long? What comes after? When the answers are only verbal, many learners cannot hold the plan.

    Without shared language

    Missed understanding

    Different speech levels, languages and processing speeds collide. The lesson becomes noise instead of one clear action.

    Without a visible order

    Hard transitions

    Moving from warm-up to skill to game without a picture board costs calm — for the group and for the instructor.

    Why we built it

    One method. Four Activity modules.

    Activity is not a random sports catalogue. It is the PixtoLearn teaching system applied to the rooms where movement happens — pool, gym, wall and mat — so the learner always sees the goal, the steps, and the order of the session.

    See Activity in the app See the swimming model

    One clear action at a time

    Clean cards show the skill — not cluttered worksheets. Focus mode keeps one picture on screen until it is done.

    Break It Down when needed

    Front: the goal. Reverse: the micro-steps. Teach with Show, Model, Perform, Repeat.

    Family mode and Session mode

    Home devices stay a child house. Floor tablets become the session board — no house UI in the way.

    How you use it

    Build once. Run on the floor device.

    Adults pick folders, build a session, and open it where the learner can see it. Focus keeps one clean card full-screen. Session mode strips the child house so the iPad is the board.

    • Browse the foldersThe same colour packs you open in the app for each sport.
    • Build the sessionFirst / Next / Then — or a longer board — with clean cards only.
    • Run FocusOne picture, one action. Less verbal noise. Clearer attention.
    • Session modeFor gyms and instructors: the device is the floor, not a child home.
