# PixtoLearn packs (local library for the web)

## Keyring
- `keyring/1` to `keyring/5`: full PixtoLearn Keyring card sets from Desktop/Pixtolearn Keyring
- `keyring-web/`: resized samples for UI and audience props

## Swimming product packs
- `swimming-jpg/pack-1` to `pack-4`: JPG exports from Desktop/pixtolearn PACK 1-4 JPG

## Existing shop assets
- `pack-basic.png`, `pack-fun.png`, `pack-full.png`, `wow-*.png`: storefront imagery already in use

Note: the full `PIXTOLEARN SWIMMING JPG` library on Desktop is ~177MB and was not mirrored wholesale. Use `swimming-jpg` packs plus `assets/flashcards` for web.
